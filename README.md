# 📊 Data Cleaning Project

## 📌 Project Overview
This project focuses on cleaning and preprocessing a dataset to make it suitable for analysis. The main goal is to handle missing values, remove duplicates, and improve overall data quality.

---

## 📂 Files in this Repository

- `uncleaned_data.xlsx` → Original dataset before cleaning  
- `cleaned_data.csv` → Final cleaned dataset after processing  
- `datacleaning.ipynb` → Jupyter Notebook containing all data cleaning steps  

---

## 🛠️ Tools & Technologies Used
- Python  
- Pandas  
- Jupyter Notebook  
- Excel  

---

## 🔄 Data Cleaning Steps Performed
- Imported the dataset  
- Checked for missing values  
- Handled missing data  
- Removed duplicate rows  
- Renamed columns for consistency  
- Converted data types where necessary  
- Saved the cleaned dataset as a CSV file  

---

## 📈 Outcome
The dataset is now clean, structured, and ready for further analysis or visualization.

---

## 🚀 How to Use
1. Clone this repository  
2. Open `datacleaning.ipynb` in Jupyter Notebook  
3. Run all cells step by step  
4. Use `cleaned_data.csv` for analysis
